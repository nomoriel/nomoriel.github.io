# nomoriel.github.io

Personal website of Noa Moriel, served by GitHub Pages at https://nomoriel.github.io/.

## Editing the content

All text lives in [`_data/content.yml`](_data/content.yml): bio, links, experience, publications,
teaching and the "Beyond research" paragraphs, plus the title and description search engines show.
Edit it, commit and push to `main`; GitHub Pages rebuilds the site within a minute or two.

Text fields accept Markdown: `[link text](https://example.com)`, `**bold**`, `*italic*`.
To add a publication, copy an existing entry under `publication_topics` and put its figure in `files/`.

## Layout and styling

- `index.html`: the page template (Jekyll/Liquid), filled from `content.yml`
- `stylesheet.css`: colors, fonts and layout
- `site.js`: the copy-email button
- `files/`: images and the CV

The sitemap is generated by the `jekyll-sitemap` plugin.

## Local preview

With Docker running:

```bash
docker run --rm -p 4000:4000 -v "$PWD":/site -w /site ruby:3.3 sh -c "gem install --no-document jekyll:3.10.0 jekyll-sitemap kramdown-parser-gfm webrick && jekyll serve --host 0.0.0.0 --watch --force_polling"
```

Then open http://localhost:4000. The page refreshes its build whenever you save a file.
